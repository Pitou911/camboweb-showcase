# CamboWeb Showcase

Portfolio site for CamboWeb's client work. React + Vite, no UI library.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All project text lives in `src/data/projects.js`. Images go in `public/img/`.

## Facebook cover

With `npm run dev` running, open `/fb-cover` (dev only, 1640 × 624) and screenshot it.

## Deploy

Works on Vercel as-is (`vercel.json` handles page routes).
